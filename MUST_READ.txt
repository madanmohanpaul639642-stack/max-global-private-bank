6. HOW TO DEPLOY ON RENDER (RECOMMENDED FOR FULL BACKEND & DOCKER)
================================================================================
Render is the ideal platform for running long-running Node.js + SQLite/MySQL backends:

[STEP-BY-STEP RENDER DEPLOYMENT]:
  1. Push this project to your GitHub repository:
       git add .
       git commit -m "Security audit and Render deployment setup"
       git push origin main

  2. Go to https://dashboard.render.com and click "New +" -> "Web Service".
  3. Connect your repository: madanmohanpal639642-stack/max-global-private-bank
  4. Fill in the deployment details:
       - Name: max-global-private-bank
       - Region: Oregon (US West)
       - Branch: main
       - Environment / Runtime: Docker
       - Plan: Free
  5. Add Environment Variables under the "Environment" tab:
       - NODE_ENV: production
       - SESSION_SECRET: <generate a random 64-character hex string>
       - DB_TYPE: sqlite
       - SEED_DEMO_ACCOUNTS: true
       - INITIAL_ADMIN_PASSWORD: <your-custom-admin-password>
       - INITIAL_TELLER_PASSWORD: <your-custom-teller-password>
       - INITIAL_CUSTOMER_PASSWORD: <your-custom-customer-password>
  6. Click "Create Web Service".
     Render will automatically build the Docker image using Dockerfile and deploy!
